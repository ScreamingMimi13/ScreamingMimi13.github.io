Practice mode is a safe sandbox — the people in it are characters and nothing you type is ever sent anywhere. Real mode needs a one-time Firebase setup.

Almost there

Real chat needs a database of its own. It's free and takes about 15 minutes — once.

What a grown-up does once

  1. Create a free project at console.firebase.google.com
  2. Authentication → Email/Password → Enable
  3. Firestore Database → Create, in production mode
  4. Firestore → Rules → paste everything from chatwave.rules → Publish
  5. Project settings → Your apps → Web → copy the firebaseConfig
  6. Paste it into the top of chatwave.html, where it says PASTE

The full walkthrough is in CHATWAVE-SETUP.md.
