Nobody's home

Real chat needs the ChatWave relay running on one computer in the house. It carries messages between phones. That's the whole thing — no cloud, no accounts.

Starting it

  1. On the computer with the games on it, open the folder
  2. Right-click wavserve.ps1 → Run with PowerShell
    (or in PowerShell: .\wavserve.ps1 -Lan)
  3. For the rest of the house, use -Lan and say yes to the firewall box — Private networks only
  4. It prints an address like http://192.168.1.12:8020/chatwave.html
  5. Type that into Safari or Chrome on the phones and iPads

Close that window and the whole conversation is gone. Nothing is written to disk. The walkthrough is in CHATWAVE-SETUP.md.
